# Prose Trail

**Prose Trail** es una plataforma web para escribir y publicar historias cortas. Su objetivo es brindar una experiencia fluida y minimalista tanto para lectores como para escritores, con un enfoque en la escritura creativa y la simplicidad de uso.

---

## Tecnologías utilizadas

Este proyecto fue desarrollado con el stack MERN y herramientas modernas del ecosistema web:

### Frontend

- React
- Vite
- Tailwind CSS
- Zustand
- TipTap (editor de texto enriquecido)
- Framer Motion (animaciones)

### Backend

- Node.js
- Express
- MongoDB + Mongoose
- Autenticación personalizada con JWT
- Nodemailer para envío de correos (verificación, recuperación de contraseña, etc.)

---

## Características principales

- Editor de texto enriquecido con TipTap
- Registro e inicio de sesión con autenticación JWT
- Verificación de correo electrónico y recuperación de contraseña con Nodemailer
- Creación, edición y lectura de historias
- Subida de imágenes de portada para cada historia
- Gestión de géneros y etiquetas personalizadas
- Página de exploración de historias públicas
- Modal de bienvenida con información del autor
- Interfaz rápida y responsiva con Vite y Tailwind CSS
- Arquitectura clara y organizada para frontend y backend
